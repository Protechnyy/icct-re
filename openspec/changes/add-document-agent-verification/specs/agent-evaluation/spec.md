## Purpose

提供一种不必重跑 OCR 和抽取就能评估核查 agent 的方式：在已保存的任务结果上重放核查阶段，量化它对关系质量的改动和付出的成本，为是否默认开启提供依据。

## ADDED Requirements

### Requirement: 在已保存的结果上重放核查
系统 SHALL 提供离线重放方式：输入一个已保存的任务结果，只运行核查阶段，输出核查后的关系列表、核查摘要和轨迹。重放 MUST NOT 修改输入的结果文件，也 MUST NOT 依赖 OCR 服务或任务队列。

#### Scenario: 重放成功
- **WHEN** 对一个包含文档原文、小节划分和关系列表的已保存结果执行重放
- **THEN** 得到核查后的关系列表、核查摘要和轨迹，输入文件未被改动

#### Scenario: 输入缺少必要内容
- **WHEN** 输入的结果缺少文档原文或关系列表
- **THEN** 重放中止并指出缺少的内容

### Requirement: 自动统计的指标
每次重放 SHALL 输出核查前后的对比指标，至少包括：关系总数、证据可在原文中定位的关系占比、不同实体名称的数量、各类改动（更正、删除、新增、实体合并）的数量，以及模型调用次数、令牌用量和耗时。

#### Scenario: 输出对比
- **WHEN** 一次重放完成
- **THEN** 输出中包含上述指标在核查前和核查后的数值

#### Scenario: 多篇文档汇总
- **WHEN** 对多篇已保存的结果依次重放
- **THEN** 除每篇的指标外，还输出全部文档的汇总

### Requirement: 改动清单供人工判定
每次重放 SHALL 导出一份改动清单，逐条列出 agent 所做的更正、删除、新增和实体合并，每条附带改动前后的内容、依据的原文和所在页码，并留出人工判定正确与否的位置。

#### Scenario: 导出清单
- **WHEN** 一次重放完成且 agent 做了至少一处改动
- **THEN** 得到一份可用表格软件打开的清单，每处改动一行，包含改动前后内容、原文依据和待填的判定列

#### Scenario: 根据判定计算正确率
- **WHEN** 人工填完判定列后把清单交回
- **THEN** 系统给出改动正确率，以及按改动类型分别统计的正确率

### Requirement: 与标注对比
当提供了某篇文档的标注关系时，系统 SHALL 计算核查前和核查后各自相对标注的精确率、召回率和 F1。

#### Scenario: 有标注
- **WHEN** 重放时提供了该文档的标注关系
- **THEN** 输出核查前后的精确率、召回率和 F1

#### Scenario: 无标注
- **WHEN** 重放时没有提供标注
- **THEN** 跳过这部分指标并说明原因，其余指标照常输出
