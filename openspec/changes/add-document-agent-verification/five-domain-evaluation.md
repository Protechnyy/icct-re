# 五领域文档核查评估

日期：2026-10-09。模型：`qwen3.8-27b`。结论：保持 `AGENT_ENABLED=false`，可以按文档手动试用，不建议默认开启。

本轮完成五篇不同领域、不同用途的虚构文档的真实 OCR、抽取、保存结果重放和逐条改动审阅。整体改动正确率为 5/6（83.33%），但没有删除样本，无法验证删除正确率门槛；出现一处实体合并错误，五篇核查均为部分完成。因此不能认定全部开启门槛已满足。

- 抽取通过现有 `vllm` requests 适配器调用指定百炼部署，模型 `qwen3.8-27b`，小节模式，batch 并发 4。核查通过独立 LangGraph 适配器调用相同模型和地址，显式 `enable_thinking=false`，串行、最多 20 任务、每任务 6 个图节点、80 次调用、600 秒。未扩大预算以改善本次结果。

## 逐条助手审阅

用户明确授权助手审阅。本轮由助手对照生成原文和预标注逐条判定，**不是独立人工盲审**。判断改动是否受原文支持、保留否定与条件；一次实体合并含任一错误则整行判错。证据扩充正确不等于关系质量提高。原始 `changes.csv` 保留空白判定，填写结果另存为 `changes.reviewed.csv`；逐条理由在 `review-notes.json`。

| design.md 决策 9 门槛 | 本次结果 | 判断 |
